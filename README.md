# XNotes for MovinkPad

面向 **Wacom MovinkPad Pro 14（Android 15）和 Pro Pen 3** 的手写笔记应用，基于 XNotes 开发。笔记保存在设备上，无需账号或云同步。

## 下载与安装

从 [GitHub Releases](https://github.com/Hshevin/xnotes-android/releases) 下载本 fork 的 **ARM64 APK**，在平板上打开安装。已安装本 fork 正式版的用户可用同签名的新版本直接覆盖升级。分支测试包使用独立包名，可与正式版并存，各自保存数据；旧 AI 和双窗格专用测试包不再纳入本地打包。当前分支测试包见[本地交付与验证记录](docs/movinkpad/branch-tests-2026-11-05.md)。

## 主要功能

- **手写笔记**：使用分页笔记或无限画布，混排手写、文字和图片。
- **PDF 批注**：导入 PDF，在页面上手写或标注文字，保留原始 PDF。
- **双窗格**：并排打开笔记或 PDF，也可同时查看同一份分页文档的两个位置。无限画布专供画画与草稿，只能单独打开，不进入分屏（[说明](docs/movinkpad/canvas-sketch-only-2026-11-07.md)）。
- **手写笔快捷键**：在「设置 → 输入 → 手写笔按键映射」先录入实体按键，再命名并分配工具、撤销或重做。工具支持按住临时使用或按一下切换；临时使用保持工具栏原有选中状态。Release 92 起可为每个录入按键另设双击动作，并调整双击间隔，也可绑定切换上一个工具、橡皮擦或平移。旧 Pro Pen 3 配置不迁移，需重新录入。Release 90 及以前仍使用原三键设置。
- **黑白界面**：支持浅色和夜间模式，以灰阶区分界面层级。
- **可选 AI**：在设置中添加一个或多个模型供应商（各自的地址、API 密钥和模型），在输入栏按供应商切换模型，从主菜单打开聊天，或在文档截图后选择「AI」。主动发送时才会将当前对话及所选截图或 PDF 内容发送给配置的供应商；联网搜索默认关闭。

## PDF 保存与备份

当前源码将 PDF 原件统一保存在应用私有目录，日常笔记只保存引用和批注，相同原件共享一份；旧笔记首次打开时迁移。通过应用分享或导出 `.xnote` 时会重新嵌入 PDF，得到可独立打开的完整笔记包。

**备份或换设备请使用应用的分享／导出功能，不要仅复制日常 `.xnote` 文件。** 清除应用数据或卸载会删除私有 PDF 原件，即使外部文件夹仍有引用式笔记，也不能据此恢复原件。迁移失败时保留原件或恢复资料，并提示处理。

此存储调整随 Release 91 本地交付，真实 SAF 提供商和目标设备迁移验收仍待完成。详见 [单份 PDF 存储与迁移记录](docs/movinkpad/pdf-single-copy-2026-11-05.md)。

## 图层功能（Release 91）

`drawing-layers` 已合入本地 `master`，新增分页笔记、PDF 批注和无限画布的常驻图层侧栏：缩略图支持不显示、已有笔记区域、整页笔记（无限画布仅前两种）、直接拖动缩略图或名称排序（无需长按）、双击名称重命名、新增、命名、显隐、锁定、删除及移动选中内容，支持撤销恢复。旧笔记归入默认层；PDF 原文保持独立。此功能随 Release 91 本地交付，真机显示与性能验收待完成，见[图层开发与验证记录](docs/movinkpad/layers-2026-11-05.md)。

## 思维导图（开发分支源码）

`codex/mind-map`（当前续作分支 `codex/mind-map-mixed-persistence`）新增原生 Kotlin 思维导图，当前尚未打包、合并或发布。在首页「新建」菜单选择「新建思维导图」，创建独立的 `.xmap` 文件；打开后进入独立编辑页。

导图编辑页现由主窗口承载，切换前等待两个窗格的笔和编辑事务结束，保留原文档与阅读位置；关闭图后返回原阅读工作区。配置重建的同会话、历史和视口保留已接线，系统选择器也不会因暂时隐藏编辑区域而改绑。Android 实际重建及 Surface／目标 GPU 场景尚未运行，详见[主窗口宿主阶段](docs/movinkpad/mind-map-main-host-2026-11-09.md)。具体来源打开与返回也已接入单文档模式，见[来源往返阶段](docs/movinkpad/mind-map-source-navigation-2026-11-09.md)。

- 文本与手绘节点混排，支持子节点、同级节点、编辑与整支删除、折叠展开并显示隐藏节点数、拖动子树、更换父节点、自动左右布局、缩放平移及撤销重做。根节点也可切换为手绘节点。
- 手绘节点内可直接用笔书写，或点「放大编辑」进入占导图编辑区域的视图；两处共用工具、内容撤销和自动保存，每笔抬起后提交。支持整笔橡皮、套索移动及显式「适应内容」，框外采样保留，不自动扩大或缩放笔迹。返回放大编辑前的图视口。文本节点双击或点「编辑节点」原位输入，确认后统一布局并形成一次撤销；取消不改正文。键盘期间仅平移视图以露出光标，退出恢复原视口和选择。类型转换和绘图区大小从「节点属性」进入。
- 文件浏览器支持预览、复制、分享及单页 PDF 导出。编辑页「另存副本」生成完整可继续编辑的 `.xmap` 备份；PDF 导出为单页阅读快照，不包含可编辑结构或可选择文字。
- 自动保存先写本机恢复日志，再写入所选文件。保存失败会提示；外部修改或损坏会阻止覆盖，可从同一文件入口恢复并另存副本。清除应用数据会删除本机恢复日志，请用另存副本做备份。

本版不支持 XMind 格式、图片附件、复杂概要／外框，也未接入通用笔按键快捷映射或前缓冲。目标设备书写、防掌触、显示与大图性能验收待完成。格式、测试与边界见[思维导图开发记录](docs/movinkpad/mind-map-2026-11-06.md)。


### 导图与关系画布扩展（当前开发源码）

导图工具条新增「自由放置节点」「脱离分支」「普通关系线」「来源」。可混排分支和自由节点，建立关联／引用自／属于／依赖于关系，编辑说明和交换方向；选中节点旁可拖动连线入口到已有节点，或轻点入口再点目标，确认后建立关系；在图内空白处落下可选择文本、手绘框或文件引用，先编辑草稿再确认，新节点与关联线一起撤销；取消不留卡片。自动布局可选左右、向右、向下，先预览再确认。节点可添加多个已有笔记、画布或导图文件作为来源，调整顺序、备注和主要来源选择，不改变正文或源文件。缺少或重复身份会拒绝添加。

普通导图继续保存 `.xmap` v3；无中心关系画布或文件卡片使用 v4，当前或保留预览目标包含 Canvas 区域时使用 v5，包含独立原 PDF 原文时使用 v6，兼容读取 v1—v6；旧应用不能打开新版本。来源列表已接最后预览和检查／刷新。手绘原位与占编辑区域放大已接入；文本原位已接入；页面引用支持整文件／文字页目录选择和明确启用（引用以页面及其上的笔记为单位，[决定记录](docs/movinkpad/reference-page-level-2026-11-07.md)）。PDF／分页笔记的页缩略图菜单新增「引用此页」：可添加到已有或新建导图，附加到已有概念节点，或创建分支／自由引用节点；保留正文和当前阅读位置，保存失败可重试且不重复追加。旧笔记首次启用后需重新打开再引用；来源版本冲突时保留原件，可另存独立副本。详见[当前页引用阶段记录](docs/movinkpad/mind-map-current-page-reference-2026-11-09.md)。

来源列表每条「打开」可打开笔记／批注 PDF 并按永久页面编号定位，也可打开 Canvas 整文件来源；引用节点只有一个来源时也可双击直达，多来源先选择具体条目。已打开来源保留其修改与撤销，其他停放文档经过保存／放弃／取消保护后收起；跳转保持单文档。点「返回导图」恢复原图视口、选择和具体来源条目。定位轮廓不写内容，首次定位前已落笔则取消自动跳转。该阶段 351 套 3771 项主机测试及 Android 测试源码编译通过，真实 Android 事件与目标设备未运行。详见[来源往返验证记录](docs/movinkpad/mind-map-source-navigation-2026-11-09.md)。

Canvas 来源已接完整单文档往返：点具体来源或双击只有一个来源的引用节点，打开原画布；已打开的画布保留原模型、撤销历史、观看位置和未保存修改。点「返回导图」恢复原图、选择和来源条目，本次返回不会额外保存停放画布。整文件来源不包含区域定位；无法完整读取的画布对象或附件会拒绝打开，保留原件与当前导图。187 项相关主机测试及 Android 测试源码编译通过，真实平台仍未运行，见[Canvas 来源阶段记录](docs/movinkpad/canvas-source-navigation-2026-11-10.md)。

Canvas 的选区／套索和截图区域菜单现有「引用此区域」：固定世界坐标范围，加入已有／新建导图及已有／新概念，保存重开后保范围与裁切预览；空区与旧图分别提示。点击来源待真实宿主稳定后定位，返回原导图的相机、选择与条目。有修改时明确保存；未保存画布可显式保存独立副本并切换继续，原文件保留，历史与保存期间的新笔迹不会被清掉。251 项有效相关主机测试及 Android 测试源码编译、独立复核通过；真实事件、SAF 与设备未运行。见[Canvas 区域来源记录](docs/movinkpad/canvas-region-sources-2026-11-10.md)。

分页笔记／PDF 的选区、套索与截图也可「引用此区域」。引用固定该页范围，重排仍指向原页；跨页或页间空隙会提示重选。可加入已有／新导图及已有／新概念，保留正文和其他来源，保存失败重试不重复添加。保存重开后保范围与预览，打开来源定位后可返回原图。PDF 可选择这份笔记的批注页面或独立原 PDF 原文；两者的来源身份与显示内容分开。281 项有效相关主机测试、Android 测试源码编译及独立复核通过；真实事件与设备未运行。见[分页区域来源记录](docs/movinkpad/paged-region-sources-2026-11-10.md)。

PDF 的整页及区域引用现先选择「此笔记页面（含批注）」或「保留并引用原 PDF 原文」。原文独立保留在本机「原 PDF 原件库」，相同 PDF 共用一份，取消加图或删除批注笔记仍可使用；可明确删除、恢复或重新关联完全相同的 PDF。打开原文进入专用只读阅读器，预览与阅读不包含笔记批注、纸张样式或插空；返回同一导图的相机、选择和来源条目，不额外保存停放笔记。范围跨插空等无法对应单一原文矩形时会提示重选。185 项相关主机测试、Android 测试源码编译及独立复核通过；真实 PDFium 像素、Android 与设备未运行。原件及恢复引用所需资料尚未纳入完整引用备份，导图副本不能替代它；见[独立原文来源记录](docs/movinkpad/original-pdf-sources-2026-11-10.md)。

原 PDF 原文现也在文件关系网络中显示独立类型，可按格式筛选，与同名批注笔记区分；删除、恢复和原件缺失会更新状态，保留已有引用及最后预览。原件库不属于普通笔记目录，目录筛选不借用批注笔记位置。全库还可列出尚未入图的原件，并加入新／已有关系画布；卡片代表整份原件，从首页进入只读阅读器，返回原图和网络的观看位置。302 项相关主机测试、Android 测试源码编译及源码独审通过；实际 Android、PDFium 像素与设备仍未运行。原件与身份资料的完整引用备份仍待完成，见[原文网络整合记录](docs/movinkpad/original-pdf-network-2026-11-10.md)。
