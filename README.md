# XNotes for MovinkPad

面向 **Wacom MovinkPad Pro 14（Android 15）和 Pro Pen 3** 的手写笔记应用，基于 XNotes 开发。笔记保存在设备上，无需账号或云同步。

## 主要功能

- **手写笔记**：使用分页笔记或无限画布，混排手写、文字和图片。
- **PDF 批注**：导入 PDF，在页面上手写或标注文字，保留原始 PDF。
- **双窗格**：并排打开笔记或 PDF，也可同时查看同一份分页文档的两个位置。无限画布专供画画与草稿，只能单独打开，不进入分屏（[说明](docs/movinkpad/canvas-sketch-only-2026-11-07.md)）。
- **手写笔快捷键**：在「设置 → 输入 → 手写笔按键映射」先录入实体按键，再命名并分配工具、撤销或重做。工具支持按住临时使用或按一下切换；临时使用保持工具栏原有选中状态。Release 92 起可为每个录入按键另设双击动作，并调整双击间隔，也可绑定切换上一个工具、橡皮擦或平移。旧 Pro Pen 3 配置不迁移，需重新录入。Release 90 及以前仍使用原三键设置。
- **黑白界面**：支持浅色和夜间模式，以灰阶区分界面层级。
- **可选 AI**：在设置中添加一个或多个模型供应商（各自的地址、API 密钥和模型），在输入栏按供应商切换模型，从主菜单打开聊天，或在文档截图后选择「AI」。主动发送时才会将当前对话及所选截图或 PDF 内容发送给配置的供应商；联网搜索默认关闭。

## PDF 保存与备份

当前源码将 PDF 原件统一保存在应用私有目录，日常笔记只保存引用和批注，相同原件共享一份；旧笔记首次打开时迁移。通过应用分享或导出 `.xnote` 时会重新嵌入 PDF，得到可独立打开的完整笔记包。

**备份或换设备请使用应用的分享／导出功能，不要仅复制日常 `.xnote` 文件。** 清除应用数据或卸载会删除私有 PDF 原件，即使外部文件夹仍有引用式笔记，也不能据此恢复原件。迁移失败时保留原件或恢复资料，并提示处理。

此存储调整随 Release 91 本地交付，Release 98 已在目标真机通过单份 PDF 与重新关联验收；真实 SAF 提供商迁移仍待确认。详见 [单份 PDF 存储与迁移记录](docs/movinkpad/pdf-single-copy-2026-11-05.md)。

### 基础编辑

- 文本与手绘节点混排，支持子节点、同级节点、编辑与整支删除、折叠展开并显示隐藏节点数、拖动子树、更换父节点、缩放平移及撤销重做。根节点也可切换为手绘节点。
- 工具条提供「自由放置节点」「脱离分支」，可混排分支和自由节点；无中心关系画布允许删到空白。自动布局可选左右、向右、向下，先预览再确认。
- 「节点选择」工具支持点选／框选、整组移动、批量删除与自由主题的六向对齐。组移动携带分支，不改变层级；中心主题与原文件不会被批量删除。每次移动、删除或对齐可一步撤销，选择与框选预览不进入保存文件、缩略图或 PDF。
- 配置重建时保留同一会话、历史和视口，系统选择器结果仍回到原请求。

不支持 XMind 格式、图片附件、复杂概要／外框，也未接入通用笔按键快捷映射或前缓冲。

### 节点内手绘与文本

手绘节点内可直接用笔书写，或点「放大编辑」进入占导图编辑区域的视图；两处共用工具、内容撤销和自动保存，每笔抬起后提交。支持整笔橡皮、套索移动及显式「适应内容」；框外采样保留，不自动扩大框或缩放笔迹，返回时恢复放大编辑前的图视口。

文本节点双击或点「编辑节点」原位输入，确认后统一布局并形成一次撤销；取消不改正文。键盘弹出期间仅平移视图以露出光标，退出后恢复原视口和选择。类型转换和绘图区大小从「节点属性」进入。

### 关系与连线

菜单「连线」可建立关联／引用自／属于／依赖于关系，编辑说明和交换方向。建立方式有三种：从关系列表选择端点；拖动选中节点旁的连线入口到已有节点，或轻点入口再点目标；点「在画布连线」再点目标。确认前不写入，重复关系定位已有线，取消不留下新线；新线确认后一步撤销。

在图内空白处落下连线时可新建文本、手绘框或文件引用节点，先编辑草稿再确认，新节点与关联线一起撤销，取消不留卡片。普通线、箭头和说明可直接点击选中，点「编辑连线」或按 Enter 修改；重合关系可在完整列表中分别选择。节点优先响应点击，选中状态不占撤销、不进入缩略图或导出。普通关系不改变层级。

### 来源引用

节点可添加已有笔记、画布、导图文件或其中的页面与区域作为来源，调整顺序、备注和主要来源，不改变节点正文或源文件；缺少或重复文件身份会拒绝添加。引用以页面及其上的笔记为单位，每页一个永久编号，画布只引用整份文档或区域，不给每笔或图片编号。

- **整文件与页面**：在导图内选择来源时可选整文件或实际页面；旧笔记启用永久页编号需单独确认，启用后需重新打开再引用。PDF／分页笔记的页缩略图菜单有「引用此页」，可加入已有或新建导图，附加到已有概念，或创建分支／自由引用节点；保留正文和阅读位置，保存失败可重试且不重复追加。来源版本冲突时保留原件，可另存独立副本。
- **区域**：分页笔记／PDF 与 Canvas 的选区、套索和截图区域菜单都有「引用此区域」。分页区域固定在该页范围内，重排后仍指向原页，跨页或页间空隙会提示重选；Canvas 区域固定世界坐标范围，空区会提示。保存重开后保留范围与裁切预览。未保存的画布可显式保存独立副本再继续，原文件保留。
- **原 PDF 原件库**：PDF 的整页和区域引用先选择「此笔记页面（含批注）」或「保留并引用原 PDF 原文」。原文独立保存在本机「原 PDF 原件库」，相同 PDF 共用一份，删除批注笔记后仍可使用；可明确删除、恢复或重新关联完全相同的 PDF。原文在专用只读阅读器中打开，不含批注、纸张样式或插空；无法对应单一原文矩形的范围会提示重选。原件及恢复引用所需资料尚未纳入完整引用备份，导图副本不能替代它。
- **调整范围与换源**：来源列表的「调整范围」「换为另一来源…」可只读查看已保存的页面、Canvas 或原 PDF，平移缩放并拖框调整，明确确认后保存，一步撤销；换源保留备注、正文和其他来源，取消不改内容。文件身份卡不提供换源；导图文件来源目前只支持整文件。
- **来源预览**：来源列表可显示最后保存的预览，检查来源变化，单条或整图刷新及取消。来源变化或失效时保留旧预览并标明状态，刷新不增加撤销步骤。预览随 `.xmap` 保存和另存副本保留，但不是来源文件的备份。未确认的新引用节点、主要来源大图及选页目录缩略图尚未接入。

文件格式：普通导图保存 `.xmap` v3；无中心关系画布或文件卡片使用 v4，含 Canvas 区域来源使用 v5，含独立原 PDF 原文来源使用 v6；兼容读取 v1—v6，旧应用不能打开新版本。

### 来源往返与反向引用

来源列表每条「打开」，或双击只有一个来源的引用节点（多来源先选条目），可打开对应文件并定位：

- 笔记／批注 PDF 按永久页面编号定位；Canvas 打开原画布，区域来源待宿主稳定后定位；原 PDF 原文进入只读阅读器；导图文件在主窗口中打开，可继续编辑、撤销和保存。
- 已打开的来源保留修改、撤销历史和观看位置；其他停放文档经保存／放弃／取消保护后收起，跳转保持单文档，导图之间跳转不额外保存停放的笔记或画布。首次定位前已落笔则取消自动跳转，定位轮廓不写入内容。
- 点「返回导图」或「返回来源导图」逐级恢复原图视口、选择和来源条目。同一导图文件共用一个实际会话，自引用和循环不会另开模型；最多暂留 16 个不同导图和 64 级返回位置，达到上限会提示。

笔记／批注 PDF 的文档侧栏有「引用与关联」：按当前页、其他页面和整份文件列出引用它的导图、节点标题、范围、备注、状态与预览。可打开图中的具体节点或来源（折叠的祖先只临时展开）；确认后仅移除那一条来源，保留节点正文、其他来源和原文件。读取失败或达到上限会说明结果不完整。画布侧的反向列表与失效来源的精确修复尚未完成。

### 文件关系网络与关系画布

首页／主菜单的「文件关系网络」无需打开文档即可查看已授权资料的全库关系，文档侧栏仍可进入当前文件的局部网络。可切换到指定多个文件，按来源集合、格式和内部／外部目录筛选，逐层展开、折叠并原位再展；切换范围保留筛选与观看位置。网络保持概念的完整来源，不把同一概念的多个来源推断成文件互相引用；可打开具体来源并返回同一网络。孤立文件显示的是上次记录的名称与位置，网络不读取其正文、不改写源文件。扫描达到上限、位置未知或身份冲突时会说明结果不完整。

原 PDF 原文在网络中显示为独立类型，可按格式筛选并与同名批注笔记区分；删除、恢复和原件缺失会更新状态。全库可列出尚未入图的原件并加入关系画布，卡片代表整份原件。

「多文件网络」中所选文件可加入新建或已有关系画布，整批一步撤销；重复文件定位已有卡片。新建以系统保存窗口的「保存」为确认。之后可点「查看画布」编辑连线、移动、保存重开，再返回原网络。文件卡片代表一个文件，标题／备注可编辑，其身份不会被当作内容引用。卡片之间的手工线会显示在自动网络及笔记／批注 PDF 侧栏的「用户手工关联」组，多个画布的同一关联聚合成一条网络线；点「在原画布中编辑」可修改或删除后返回。可选的同图出现与失效检查尚未完成。

### 双窗格与混合分屏

- 导图可与笔记／批注 PDF 并排：从笔记分屏后的文件首页、文件的「在旁边打开」或导图的「在旁边打开」进入；也可在首页同时选择一份导图和一份笔记／批注 PDF 一次打开，两份都核实成功后才一起采用。两侧独立编辑和撤销，支持调整方向、比例及交换位置。
- 点击来源时优先定位另一侧已打开的笔记，否则经保存保护替换该侧；页／区域引用可直接选择另一侧已开的导图。关闭来源子图先返回父图，关闭根图进入该窗格首页，再关闭首页才移除窗格。
- Canvas 仍只能单独打开，从 Canvas 返回为导图＋首页；独立原 PDF 返回时若原阅读会话已变化则安全回到单图。
- 应用内保存的笔记／PDF 分屏、最近分屏和双选两份笔记可替换当前导图工作区：先核实两份文件和旧文档保存状态再一起切换，缺件、坏文件或取消不会先关闭原文档；录音中的文档需先结束录音。
- 「保存分屏」在两份内容实际保存成功后发布安排，Saved／最近分屏可显式重开并恢复比例、方向、交换、焦点与阅读位置。混合安排使用 `.xsplit` v3，仍可读取 v1—v2 普通笔记分屏；首页或停放布局不作为完整安排保存。

普通打开或调整布局后会自动保留最后呈现：单图、导图旁首页、导图＋笔记／PDF、分页文档与单独画布。恢复时先核对本机正文与身份；坏、未来版本或缺件保留恢复资料，可重试、查看资料或明确重置布局记录。仅没有新记录时使用旧会话恢复。此能力已纳入 test6，真实进程终止待设备验证。

尚不支持：导图＋导图／同一导图双视图。混合布局完整进入全局网络／原件库再返回、预览体验、精确来源恢复与完整引用备份等仍在[接续计划](docs/movinkpad/mind-map-next-plan-2026-11-11.md)中。

### 保存、恢复资料与另存

- 导图自动保存先写本机恢复日志，再写入所选文件；保存失败会提示，外部修改或损坏会阻止覆盖，可从同一文件入口恢复并另存副本。清除应用数据会删除本机恢复日志，请用「另存副本」做备份。
- 文件浏览器支持预览、复制、分享及单页 PDF 导出。「另存副本」读取实际存盘内容，生成完整可继续编辑的 `.xmap`；非空目标拒绝覆盖，写后失败可明确继续。PDF 导出为单页阅读快照，不含可编辑结构或可选择文字。
- 笔记与画布保存时校验页面身份与来源版本，失败保留资料与未保存状态；已写入的版本不会自动回滚，「放弃修改」只放弃之后的新修改。打开文件先完整读取和验证再替换工作区；保存后重新打开会读取刚写入的版本。
- 分页笔记的首次保存／另存按独立文档发布：已启用引用的副本取得新的页编号，原引用仍指向原文件；保存期间新增的内容保留为未保存修改。PDF 沿用共享原件并保留原始字节。
- 首页导航的「恢复资料」可逐页预览窗格保留的笔记／画布资料并保存独立副本，原资料和当前文档保持不变；写后失败可「继续此副本」，重启后可「继续未完成的副本…」明确选择原目标。
- 本地源码恢复的旧分页／画布工作副本可继续编辑；保存时先另存独立文件，避免仅凭记忆路径覆盖原件。取消或失败保留恢复内容；关闭同一文档的另一视图会保留实际文档。画布另存后可继续编辑和普通保存；关闭受保护副本时须明确另存或放弃。此保护与自动布局恢复已纳入 test6，待设备验证。
- 本地源码在插入菜单提供「录音恢复…」：可明确恢复、作为独立录音加入、导出原始音频或保留以后处理。原始音频保留至文档实际保存并包含它；已加入但未确认保存的录音不会在重启后擅自重放。
