# XNotes for MovinkPad

为 **Wacom MovinkPad Pro 14（Android 15）与 Pro Pen 3** 定制的手写笔记应用，基于 [XNotes](https://github.com/shardulvs/xnotes-android) 开发。笔记以文件形式保存在你选择的文件夹里，无需账号。

## 功能

- **跟手的笔迹**：压感、低延迟，钢笔、荧光笔、霓虹光晕与会自动消失的笔迹。
- **分页笔记与无限画布**：需要结构时用分页，需要空间时用画布；画布专供画画与草稿。
- **思维导图**：在画布里直接建导图，节点内可手写，可链接到笔记页面或整张画布。
- **图层**：分页笔记、PDF 和画布都有常驻图层侧栏，可排序、显隐、锁定，带缩略图。
- **PDF 批注**：导入 PDF 直接书写，可加宽页边留出旁注空间，支持文字高亮、下划线、删除线与评论。
- **双窗格**：并排打开两份笔记或 PDF，也可同时看同一份文档的两个位置。
- **Pro Pen 3 与其他手写笔按键**：录入实体按键，绑定工具、撤销或重做；支持按住临时使用、按一下切换和双击动作。
- **可选的 AI**：截图或附上 PDF 向自己配置的模型提问，支持多个供应商、思考深度和联网搜索；只有点击发送时才会联网。
- **黑白界面**：浅色与夜间模式，用灰阶区分层级；夜间模式下黑色笔迹自动显示为白色。
- **形状吸附、胶带、模板**：画个大概形状后停住即可变规整；胶带遮住答案点按揭开；20 多种页面模板。
- **文字与排版**：Markdown、表格、LaTeX 公式和代码高亮；文本框可放在页面任意位置，单独设置字体、颜色、填充和边框。
- **只读模式**：看笔记时收起工具栏，防止误写，翻页和目录仍在手边。
- **录音**：边写边录，笔迹随录音同步回放。
- **真正的 PDF 导出**：矢量笔迹、可选中文字、保留链接与书签。
- **文件夹即笔记本**：网格、画廊、列表、分栏和时间线视图；可在多个文件夹之间切换。
- **可靠保存**：自动保存；未保存修改在离开应用或保存失败时自动保留会话副本，重启后恢复。
- **随时可改**：笔迹不会被压平，每一笔都能移动、改样式或擦除。

## 下载安装

从 [GitHub Releases](https://github.com/Hshevin/xnotes-android/releases) 下载 `XNotes-<版本号>-arm64.apk`，在平板上打开安装。新版本可以直接覆盖安装旧版本，笔记保留。

- 最新版本：[0.9.9beta](https://github.com/Hshevin/xnotes-android/releases/tag/v0.9.9beta)。装上后不能再回装 0.9.8 及更早版本。
- 备份或换设备时，请用应用里的分享／导出，不要只复制 `.xnote` 文件：PDF 原件保存在应用内部，导出时才会一起打包。
- 旧版独立导图（`.xmap`）和导图混合分屏已不再支持，旧文件不会被删除或改写。

## 从源码构建

需要 JDK 21、Android SDK 36、NDK 27.0.12077973 和 CMake 3.22.1，在未提交的 `local.properties` 中设置 `sdk.dir`。

```bash
git clone https://github.com/Hshevin/xnotes-android.git
cd xnotes-android
JAVA_HOME=/path/to/jdk-21 ./gradlew assembleDebug
```

只构建 ARM64。签名、测试版包名与发布流程见 [AGENTS.md](AGENTS.md)，开发记录见 [文档索引](docs/movinkpad/README.md)。
