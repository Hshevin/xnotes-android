1. **工程与复用。** 先读 AGENTS/MOVINKPAD/README/project-brief 和 Git 状态，保留用户修改；遵守现 Android 工具链、图层、原始笔事件、保存、双窗格、黑白主题、字号／间距 token、48 dp 触控区和三套中英文资源。原生 Kotlin、独立 `.xmap`，优先复用现编辑／渲染／撤销／身份能力，不另建 WebView 或编辑引擎。临时文件进忽略的 tmp，Python 环境用 uv。开源参考只在源码和许可证核实后复用，保留版权；不引入账号、云、后端或 AI 依赖。

2. **概念与多来源。** 节点正文可为文本、可编辑手绘，或仅来源；都可附多个文件／同文件多个位置，节点在图内有稳定 ID，不要求独立文件。来源独立保存范围、备注、状态和最后预览。正文下“来源 N”展开文件名、位置、缩略图、备注／状态，能添加、移除、排序、调范围和指定主要预览。显示标题、来源备注、原文件名独立；改标题不改文件名，增删来源不清正文。

3. **两种组织方式。** 导图有中心、父子层级、同级顺序、折叠和隐藏数量，先支持左右／向右／向下；关系画布可无中心、多个自由节点及手动连线。一图允许自动分支与自由节点混排，添加时区分加入分支／自由放置，子／同级节点可选文本、手绘或引用。父子无环，普通线不改层级，自由位置持久化。主动整理先可取消预览，确认整次一步撤销。

4. **笔与文本编辑。** 手绘内容区落笔直接写；落笔锁定节点归属／原变换，越界不转给其他节点，显示裁切不丢采样。书写时框和布局稳定，“适应内容”才主动调整后整理；改变框尺寸不默认缩放笔迹。手指碰内容区不拖节点，保掌触／取消，笔接触不并发启动画布手势，笔中不切工具；橡皮／套索限当前节点。双击／放大按钮进入当前窗格的大编辑面，共享内容、工具和内容撤销，返回恢复视口／选择、不整理。文本双击或按钮原位输入，组合输入正确，键盘避让，确认后布局。引用节点双击打开；有正文仍编辑正文，多来源须点具体条目消歧。

5. **拖动、多选、历史。** 标题／边框／手柄超过系统阈值即拖，无需长按；自由节点连线随动。分支拖整棵子树，预览新父／同级位置，禁止自身或后代，非法恢复。显式脱离为自由节点，边缘自动平移，取消零模型提交。节点框选和手绘套索分开，多选组移动／删除／自由布局对齐。选择、视图、进出放大不占内容撤销；每笔、移动、换父、连线各一步，新建并连线一步。

6. **连线。** 支持边缘入口拖到目标和点击连线后点目标；临时线／目标反馈，落空可选文本／手绘／引用并连接，取消无残留。关联默认无向，引用自／属于／依赖于方向清楚，支持说明、交换方向、改端点／类型／删除。自动走线随节点更新，宽命中、重叠节点优先，重复同端点／类型／方向定位已有线。普通线删除不删节点；层级拆除经换父／脱离。

7. **从文档创建来源。** PDF 页面菜单“引用此页”，区域选择／手写套索有添加到图入口（按最新页面级决定说明实际范围，不冒充对象跟随）。可选已有／新图、已有概念／新引用节点；另一窗格已打开图时优先提供。成功选中新卡但不强制打断阅读。引用与复制副本区别清楚。PDF 区域可选原文或含当前笔记批注，后者仅有相应上下文时出现，不能混淆共享原 PDF 与某份批注笔记。

8. **范围语义。** 当前以文档 UUID／永久页 UUID 定位，区域只是固定页／画布范围提示，不用位置或相似度猜身份，不恢复对象编号。页重排跟原页，删页保持已删除而不指向别页，复制得新页号。区域当前空与内容／页面删除区分；引用不得重编码旧笔迹。跨页／图层、删除和撤销恢复均需验证现身份与范围语义。

9. **跳转与返回。** 单文档打开并定位来源，有返回图入口，不自动创建／恢复分屏。双窗格优先定位已开来源，否则另一窗格打开，替换遵守保存／失败保护。定位页／区域短暂对比轮廓，不写内容，失败保图，返回保视口／选择和具体来源。无限画布按后续产品决定只独立打开，不强行恢复画布分屏。

10. **反向引用。** 文件侧栏“引用与关联”分当前页／区域、其他位置、整文件、用户手工关联；显示图、节点标题、范围和预览，能定位精确节点／来源条目。自动由真实来源生成，不手工双向维护；默认不铺满来源标记，可主动显被引区域。移除明确哪图哪条来源，不删整个节点或原文件。

11. **文件网络。** 当前文件局部、目录／类型／指定集合筛选，可选全库；UUID 去重，重复引用可聚合数量并展开位置。严格分内容引用、用户显式关联、可选同图出现；多来源概念不推导文件彼此引用或依赖，可展开中间概念解释。局部默认直接，逐层展开／折叠／筛选及失效检查。自动图用于探索，手工位置保存进关系画布，并能将所选文件加入关系画布。显式文件卡片的线与普通多来源概念区别清楚。

12. **变化与恢复。** 内部改名／移动保持引用并更新展示；外部移动／权限失效暂不可访问，可定位／重授权。缺／重复身份显式恢复，不任选同名文件。来源变更提示预览待刷；删页／内容缺失保卡和旧图，区域空单独状态；回收站可恢复，永久删除仍保失效引用和正文。默认保最后预览，单条／整图刷新，旧预览明确不是最新。失效不得导致编辑覆盖源文件。“定位原来源”与“换为另一来源”分开，换源重新选范围并明确告知。PDF 原件恢复继续严格原 SHA-256，不可换底稿。保留独立副本：可读原对象才保可编辑内容，只剩预览只可保图片，不称恢复笔迹。

13. **保存、备份、性能。** 图／节点／来源／关系／手绘／布局可靠持久化，异常退出恢复、保存失败、损坏数据、旧笔记兼容明确。预览不是完整备份；区分图像／PDF 快照、可编辑备份、是否含引用文件。引用 PDF 完整备份走现应用导出，不只复制内部引用包。刷新／清理不能删共享原 PDF，遵守引用／租约／回收规则；大 PDF 按需合批预览、可取消，不每卡完整解码或复制。

14. **实施与验收。** 持续交付真正流程，检查现能力、模型改动、验收和阶段依赖，但不只交方案。优先来源创建→多来源正文编辑→层级／普通线→保存重开→来源往返→反向引用→变化恢复，再完善文件网络。验证多来源、页／文档身份、历史、移动删除、SAF 恢复、保存失败、双窗格和笔冲突；平台项目不能仅以 JVM 替代，渲染／Surface／前缓冲／GPU 单列目标设备边界。目标设备 MovinkPad Pro 14／Android 15／Pro Pen 3；未运行必须明确。阶段完成自动本地提交，剩余需求持续保留，整体未完成不能标完成。
