# 文件关系网络筛选（2026-11-09）

用户要求：沿原计划持续实现文件关系网络的文件夹、类型与指定集合筛选，以及随后逐层展开、折叠和全库等剩余需求。

本轮边界：代码、编译／测试、文档与通过验证后的本地提交；不打包 APK、安装、推送、合并或发布。

当前局部网络以原文件 S 为中心。筛选条件作用于真实来源文件；所属图仅作解释上下文，不因格式为导图而自动满足条件。一个概念只要有来源文件匹配，即保留它的全部来源及所属边，其他文件明确属于解释上下文，不将来源裁成半组或生成文件间的依赖。条件组合为指定 UUID 集合、原生文档格式及文件夹。不限与空选择分开，未知类型／位置不猜测，空结果中保留未能判断的信息。

格式使用上次识别的原生类型：分页笔记（含 PDF 批注）、画布、导图。文件夹先核实际目录与所属关系，但登记位置仍不等于当前文件身份已核实；界面明确这些信息的时间边界，打开来源继续走原 UUID／永久页校验。筛选不读取或复制完整笔记／PDF，不给来源保存权限，不改源文件、工作区或内容撤销。

实施分两片：先纯筛选与只读元信息及行为测试，再接 Controller、弹窗草稿、应用内部只读目录与外部临时文件夹选择（不把新筛选目录持久登记为资料库）、主界面与相机／输入回归。有效筛选变化永久退休旧打开票；C1／取消／关闭后迟到的元信息不覆盖新结果。默认无限制时保持 D1 读取和输入行为。筛选在场景预算前进行，仍按完整概念计算 250 节点／750 条实际边及 5000 成员上限。

D2a 是当前局部网络的条件筛选，不能代替集合多中心或全库网络。逐层展开／折叠紧随其后，需要真实本层来源锚点与有界隐藏位置缓存，不能伪造为原 S 引用。显式手工关联、可选同图出现、失效检查、加入关系画布与原区域／画布引用、双窗格及恢复等需求全部保留。

具体可观察验收：多来源匹配保留整概念，owner-only 不匹配、owner 同时是真实来源才匹配；类型与文件夹未知明确；取消草稿不变；A→B→A 过滤不复活旧动作；异步 C1／关闭隔离；同一图的具体来源仍可往返。真实 SAF、系统选择器、Android 15／MovinkPad／Pro Pen 3、GPU 与仪器执行单列，不用 JVM 结果代替。

独立计划复核要求已纳入：默认内部资料库不出现在系统文件夹选择器，须有应用内部目录入口；来源条件统一同一source的AND语义，所属图仅上下文。位置总量/每身份/问题与目录项有全局上限；已删除owned路径不可凭provider的isChild=true当作存在，不创建目录以探测存在。筛选草稿绑定原控制代次。

内部目录选择仅纯构造 URI；存在性与列表使用不创建的实际目录路径。现有 AppStorage provider 的 treeUri/query 会间接创建根，因此筛选不调用这些路径；根不可用返回未能确认，不自动创建或切换存储根。

## 实际接入

在局部关系网络点「筛选」，可组合当前已知来源 UUID 集合、分页笔记／PDF／画布／导图格式，以及应用内部子目录或系统选择器返回的外部目录。全部不限与空选择不同；取消草稿不改查询。指定集合是当前局部网络条件，不是任意文件的多中心网络。

控制器保留未筛选来源清单，在 250 节点／750 实际边预算之前判定整概念。只要同一个来源满足所有条件，保留概念的全部精确来源和所属边；不匹配的来源只作解释上下文，owner-only 不满足来源条件。筛选不写 `.xmap`、来源、正文撤销或原生工作区，不自动适配视图。目录／元信息状态为不改变 Canvas 几何的叠层，原有效选择与相机保留，消失选择清空。

格式是登记表上次识别值，不依文件名推断 PDF，不重新解码来源。即使记录已失效或所有位置被移除，可靠的已知格式仍能匹配；文件夹条件另要求本次目录／位置事实，失权、缺失、重复或不能确认时明确为未知。源状态和可打开权限不因此改成有效。内部目录通过不创建的实际文件路径读取；外部目录授权仅用于只读元信息，不持久化新目录授权，不改变默认资料库。

有效条件变化退休原打开票与草稿版本；A→B→A 不重签旧动作。元信息任务冻结投影与代次，源 C1、新扫描、取消、关闭及宿主替换后晚结果不能覆盖；最终提交还核实际图观察寿命。系统选择请求各有独立 runtime key，关闭草稿只退休 payload，旧系统结果先消费原槽而不能写新草稿；重建后旧请求不领新 callback。目录名称查询与事实查询均使用实际取消信号和应用上下文，取消后迟到游标关闭。
