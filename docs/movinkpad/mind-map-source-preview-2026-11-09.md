## 实现边界

本阶段延伸已有节点「来源」列表。可见来源首次无图片时按需生成；已有图片先检查状态，来源变化后保留旧图片，需用户明确刷新才替换。提供单条检查／刷新、整图检查／刷新及取消。未确认的新引用节点草稿不预先往图中写入图片。

分页来源按永久页编号定位，区域仅是 `.xmap` 中的页面局部提示；整份笔记取首页、画布取内容范围、导图取整图。预览来自存盘版本，不代表另一编辑器尚未保存的草稿。当前不在主画布节点内绘制主要来源大图，选页目录仍为文字目录；这两项继续保留。

同一批请求按文档身份分组，共用实际来源快照、解码结果和 PDF 会话。可见行的自动请求需在同一轮合并，避免每卡解码整份原件。读取不创建新 Editor，不采用来源为编辑文档，不升级身份、不改源文件。原 PDF 仍受既有租约和 SHA-256 核验保护。恢复预览与来源卡复用只读 CPU 绘制能力；普通浏览器缩略图保留其视图样式路径，不改 GL／前缓冲。

## 保存与状态

`.xmap` 写版本 3，兼容读取 1／2。旧版本应用拒绝版本 3，避免在编辑后静默丢掉图片。预览直接进入现有图文件与恢复日志，不增加第二套保存服务。另存副本只换图身份，保留外部来源目标及 PNG。

每个最后预览分别记录图片摘要、实际描绘的文档／页面／区域、渲染版本与生成时间。更换目标后旧图仍绑定原目标，界面标注「原引用的预览」；无法读取、页面删除、刷新失败不清空旧图。状态与来源正文／备注独立。原件暂不可读不等于永久删除，缺少或重复身份不猜同名文件。

已证明的空区域也保留旧图，并明确显示「区域当前为空」及最后保存预览说明。当前仅在区域与纸面无交集时证明为空；纸面内无笔迹／对象的空白区域检测仍待完善，不能据白色像素猜测。空区域证明只用于同一目标及已核对的版本；来源变化使其失效，范围变化重置状态。明确刷新可接受空结果而不伪造一张新图片，未接受新基线的初次自动读取仍显示变化。

来源原始 SHA 是选择或明确刷新接受的存盘基线；缓存观察版本不提供写来源权限。导图预览使用带域标识的语义摘要，排除状态、预览、观察时间等派生字段，防止图引用自己或图相互引用后每次保存都显示变化。首次自动预览发现原来源已变时仍保留「已变化」，直到明确刷新。

派生预览更新不新增内容撤销步骤、不清空重做；它合并进当前及匹配目标的历史帧，保留正文、备注、排序及主要来源。IO 逐帧校验完整文件预算并立即丢弃编码字节，Main 只原子采用仍属于同一历史代次的结果。正文编辑期间重准备派生合并，不重复渲染；目标或来源存在性变化则退休原请求，包括删除后撤销和目标 A→B→A。

## 图片输入边界

资产工厂持有不可变 PNG 字符串，每次取字节返回独立数组。限制实际尺寸、压缩字节、总像素／字节和资产数，校验 SHA-256、规范 base64、chunk CRC、完整 IEND 与有界 inflate。仅接受自有静态 8 位非交错编码 profile，不作为通用图片导入器；压缩配置、动画和未知 metadata 不进入 BitmapFactory。PNG 的类型与顺序约束参考 [W3C PNG 规范](https://www.w3.org/TR/png/#5ChunkOrdering)。

预览不是源文档备份。完整可编辑备份仍需同时保留图和引用文件，引用式 PDF 沿用应用导出原件的机制，不能只复制内部引用笔记。
