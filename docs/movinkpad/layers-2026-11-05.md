# 图层第一版 — 2026-11-05

状态：开发分支 `drawing-layers`，尚未打包。用户授权本轮代码实现、验证、本地提交和推送该分支；未授权 APK、设备安装或 Release 发布。

## 功能与范围

- 分页笔记和 PDF 每页独立图层；无限画布整张画布一组图层。
- 文档栏的图层入口支持新建、重命名、上移/下移、显示/隐藏、锁定/解锁、删除及将选中内容移到指定层。选中行使用反色，中文与英文资源齐全。
- 新建层自动成为当前层；手写、橡皮、框选和套索只操作显示且未锁定的当前层。粘贴归入当前层。至少保留一个层。
- 删除有确认，图层结构修改和移动选中内容进入原有撤销栈。删除恢复对象、成员关系和对象顺序；无限画布同时恢复空间索引。
- PDF 原始页面、纸张/模板、PDF 文字标注和跨页排版正文保持独立。本版管理的是画布对象（手写、形状、文本框、图像等）；没有把跨页正文拆成用户图层。
- 导出、截图与缩略图遵循可见图层顺序。图层面板属于每份文档的独立控件，在所有笔记/PDF/画布分屏组合中不进入共用工具栏。

## 存储与兼容

- 没有图层字段的旧对象归入 `default`。未改动的默认单层保持历史 manifest 字节形式；有多个层或自定义层设置时增加 `layers` 元数据与对象 `layer` 字段。
- 不重编码原始 PDF；图层功能不修改笔迹样本简化规则。保存仍走现有原子写入和失败恢复路径。
- 分页和无限画布的后台保存快照分别冻结图层元数据及对象成员 ID，防止保存过程中移动对象或删除图层导致悬空引用。
- 空图层列表、重复 ID、无效当前层和对象悬空层引用拒绝加载，避免静默误分层。原文件不被更改。
- 老版本应用不认识新增图层语义，不能用它回存多层文件来保留层结构；本次的兼容承诺是新版本读取旧笔记。

## 渲染选择与验收边界

- 单层保留原有缓存与前缓冲路径。分页多层在独立缓存的页面背景上，按图层顺序绘制可见区域内的对象与当前层实时预览；现阶段未实现逐层持久化显示缓存。
- 无限画布沿用 GPU 几何与空间索引，在当前层边界合成实时笔迹/形状，按层序绘制荧光笔及霓虹光晕。
- 多层不将实时笔迹放到最上方的独立前缓冲，否则下层笔迹会遮住上层图像。用户前缓冲偏好不被改写，单层可继续使用；不改变湿墨 View 跨宿主重挂规则。
- 真机待验收：MovinkPad Pro 14 / Android 15 / Pro Pen 3 上的层间实时遮挡、重排、荧光笔/霓虹、分屏与翻页、取消笔触、长时间书写延迟，以及多层密集页面的帧率和内存。没有由 JVM 或编译结果推断硬件兼容性。
