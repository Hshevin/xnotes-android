# AI 原始报错展开与 OpenCode 风格配置文件编辑器（2026-11-22）

用户要求：AI 请求失败或拒参降级时在保留一行摘要的基础上支持点按展开原始报错（带一键复制）；在 AI 设置中提供整套配置的 JSON 文件编辑与导入／导出（密钥默认脱敏隐藏），支持按供应商和单模型自定义思考深度对应的请求体 JSON 字段与输出上限字段，同时提供对应的可视化 GUI 编辑入口。分工：主代理负责前端界面与全部测试用例，`gpt-6.2-astra` 负责后端实现与测试复核。
状态：已实现；JVM 单元测试与 Android 仪器测试源码编译通过（本机 JDK 21）；真实供应商响应与 MovinkPad 真机交互待验证。
本轮边界：源码、测试与文档本地提交；不打包 APK、不安装设备、不推送或发布 Release。

## 改动摘要

1. **AI 原始报错展开与一键复制**
   - `AiProtocol.formatRawError` 统一记录脱敏后的请求摘要（HTTP 状态、接口路径、模型、思考字段 JSON、工具开关）与格式化后的原始响应体（单条上限 16 KiB，遮蔽 API Key 与搜索密钥）。
   - `AiTurn` 持久化 `rawError`，失败轮次以及思考参数被拒后自动降级成功的轮次都会保留原始拒绝详情；界面在单行摘要下方提供「原始报错」折叠入口，展开为等宽文本块并提供「复制报错」按钮。
2. **OpenCode 风格分层 AI 配置文件（JSON 与导入／导出）**
   - `AiConfigFile` 覆盖整套 AI 设置（默认供应商／模型／思考深度、输出上限、自定义提示词、默认联网／附带 PDF、搜索密钥、图像模型以及全部供应商）。
   - 思考档位支持三层优先级：`modelOverrides[model].thinkingLevels` > 供应商 `thinkingLevels` > 内置 `thinkingFormat`；每个模型还可单独指定 `tokenField`（自动 / `max_tokens` / `max_completion_tokens`），发送时拒绝保留协议字段（`model`、`messages`、`stream`、`tools`、`tool_choice` 等）并校验自定义档位数量与名称。
   - JSON 视图与导出默认以 `***REDACTED***` 隐藏全部密钥，提供「显示明文密钥」切换与「不含 API Key（推荐） / 包含 API Key」导出选项；导入支持「合并导入（保留已有）」与「覆盖全部」，脱敏或留空的密钥仅在供应商主机一致时自动沿用本机已保存密钥，避免跨主机静默泄漏密钥。
   - 文件读写均在 IO 线程执行并对导入流增量限流（最大 2 MB）；查看或导出未修改的 JSON 以及仅修改无关字段时不会把继承的默认思考档位固化为显式覆盖。
3. **可视化 GUI 配置入口**
   - AI 设置顶部新增「可视化设置 / 配置文件 JSON」双向切换；切换前校验输出上限等当前编辑值，合并导入前保留 JSON 编辑器内未保存的改动。
   - 供应商编辑页新增「思考深度请求字段」可视化编辑器（支持增删改、恢复格式默认，并阻止同名档位静默覆盖）；每个聊天模型行新增「参数覆盖」入口，可在弹窗内可视化设置该模型的输出上限字段与独立思考档位映射。
