## R2b1a

`NotebookStorage.identity` 不再把快速 ZIP 布局不支持误认为没有身份。支持的布局使用 `BundleHeader`；明确不支持的布局或不可 seek 描述符从 URI 起点重新取得一次私有快照。解析或权限错误不返回 null，只有真正没有身份元数据的旧包才返回 null。

带页面引用标记的包在同一快照检查 Header 绑定、ZIP 中央目录与物理条目一致性、全部页面 UUID。快读与快照观察的文档身份或标记有无不一致时拒绝，避免读取期间发生降级或替换。不会解码笔迹和 PDF；全包校验会读取负载，当前仅用于来源/打开身份检查，不能据此在每张卡片渲染时反复调用。

返回身份前查询位置和文档 UUID 两种契约。`ensure` 在迁移前使用该入口；已经登记的位置被换成另一身份，或外移文档丢失已知页契约，均拒绝并保留原件与登记。来源选择和重新发现原生笔记/画布也使用该入口。普通旧包仍保持原有读取方式，不在这一步分配页编号或登记正页契约。

`ensure` 有 pending 时不再先用空验证回调自动发布候选，而是保留所有恢复资料、提示处理恢复；完整恢复校验接通前不恢复自动继续。普通添加来源、重新发现文件及打开/重新定位入口将协程取消检查传入真实 Header/快照链，外层不吞取消；其他同步身份调用可不传取消信号。格式失败映射为中英文 StorageMsg，保留 cause；引用契约错误和取消原样透传。失败清除本次私有快照，不改源文件。

边界：本片仅覆盖 `.xnote` / `.xcanvas` 的身份读取。`.xmap` 来源的等价位置替换检查、正页契约登记、所有保存/显式恢复的完整 guard、pending PDF 持久保护和页面引用激活仍待 R2 后续，不能宣称完整来源闭环已可用。
