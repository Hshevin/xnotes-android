## 身份与迁移

`.xnote` / `.xcanvas` 新增独立 `xnotes-identity.json`，已有 manifest 版本保持不变。文档 UUID 与 PDF 内容指纹分离，编辑/快照保持 UUID，显式复制、另存与保存分叉生成新 UUID。外部复制带来的重复 UUID 会提示冲突，不采用最后打开者覆盖。

旧包打开时先准备独立候选文件，逐条核验原始负载的 SHA-256，包括未知字段、笔画和 PDF；不会用模型重新编码来迁移。普通 ZIP 追加元数据保留原压缩负载，注释/Zip64 回退逐条复制并核验解压字节。本地文件验证后原子替换；SAF 先保存持久原件、候选件与待发布标记，写后复核，失败保留恢复资料。遇到外部修改不覆盖，提供恢复原件或显式保留当前有效 ZIP 的处理。

只读旧文件不能自动写入身份，界面明确报告权限问题，需要重新授权或可写副本。旧笔画保真仅约束导入/格式升级，普通笔画简化逻辑未改变。

## 位置与界面

SQLite 登记文档、规范化 URI 位置及资源引用。树 URI 与直接文档 URI 使用 authority/documentId 去重。应用内移动和重命名更新位置；外部失联可以重新选择文件，验证 UUID 后定位，或由用户触发在已授权树中搜索（最多 5000 项）。没有启动时全盘扫描。

分屏记录 v2 保存两侧 UUID 和独立视口，仍读取旧 URI 记录。失联或冲突窗格保留占位与视口，另一侧可以继续使用。最近记录与 AI 来源保存 UUID，跳转前核验身份，避免同名路径被替换后打开错误文件。失联最近记录保留在存储中，目前列表隐藏不可解析项；专门的最近失联列表仍待完善。AI 来源支持重新定位；文档内浮窗按文档 UUID 归属。

## PDF 资源与生命周期

分页笔记打开时直接把包内 PDF 流登记到 noBackupFilesDir/ai-pdfs 的不可变内容对象，编辑器和 AI 共用该对象。外部 PDF 附件仅在明确选择后接收，发送后才交给模型。不同内容生成新指纹 ID，旧会话保持旧版本；目前以内容 ID 表达版本，数据库 version 字段为 1，没有顺序修订号界面。

便携笔记 ZIP 仍嵌入原始 PDF，保证旧读取器和导出兼容；共享的是运行时持久对象，并非删除便携包中的原件。资源登记包括路径、大小、指纹与版本。相同运行时对象避免重复复制，原件不修改。

笔记、聊天、草稿、删除撤销分别持有引用；生成通过租约保护。引用先保守保留，再随历史原子发布收敛；失败不会先删掉旧引用。笔记暂保留观察到的 PDF 版本直至永久删除。回收只删除受管目录内、无引用、无有效租约且超过 7 天保留期的对象，外部原文件不参与删除。损坏历史或引用恢复失败时暂停自动回收。进程内活跃租约不会因数据库到期时间经过而丢失保护。
