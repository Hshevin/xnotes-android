## 文件浏览器副本

首页文件浏览器的「另存副本」固定原来源与本次选择器请求，复用已有独立请求的目标选择器。返回后先核目标，不在界面层提前打开写流。副本读取已存盘文件，不保存或采用正在编辑的草稿。

笔记／画布复用 NativeCreation 的空目标发布、独立文档身份及原字节投影。已启用页面引用的笔记副本取得新页编号；旧笔记的复制不自动启用页面编号。外部 PDF 在有界元数据读取后先持租约，再做完整扫描与编码，租约持续到目标发布结束。导出的便携副本内嵌原 PDF，保留笔迹、未知负载及非元数据条目；共享导出保持原文档与页面身份。

非空目标、来源自身、已登记页面契约丢失均拒绝，不打开目标写流或删除目标。取消独立传播。写后登记失败保留确切候选，可从已有恢复资料明确继续，不重新分配编号、不采用副本、不改变原编辑器路径、撤销或视口。

`.xmap` 继续使用 JSON 和 MapStore，不经过笔记 ZIP 编解码器。实际 MapSession 与文件浏览器副本共用空目标创建：先保存本地候选，再重读目标仍为空后写入，并读回核对。失败保留同一候选，后续显式恢复续完；新的复制请求不覆盖既有日志。

同一实际文件的 SAF URI 别名共用锁。日志查找兼顾当前 URI、可构造的直接文档 URI 及登记表中同一位置的已知别名；冲突或孤立的 staging 保留并拒绝覆盖。完全未知的历史 URI 只留下哈希文件名，无法反推出归属，本片不猜测。只有本次确切拥有、尚未完整写入并同步的 staging 可在失败时清理；已同步的恢复资料保持。

## 页面身份启用存储接口

新增显式 `activatePages` 与 `completePageActivation`，暂未接入用户页面来源界面。首发要求实际来源版本仍匹配位置、类型、文档身份及摘要，而且目录确为 NeedsActivation。已有合法页编号时重新核实与登记，不重新生成编号；孤立、缺失、重复或损坏的页元数据拒绝。

原字节候选复用 BundleAnchors：除页编号与标记外，保留原 manifest 片段、笔迹及所有其它负载。首发和恢复均完整证明 A→B 只进行了这个有限变更。发布固定本次实际记录摘要及候选摘要，拒绝后续替换成另一份合法但不同编号的候选；当前文件只接受保留的原版本 A 或候选 B，部分写入或外部 C 均保留资料并拒绝。

新增 ACTIVATE_PAGES 目的与普通保存、新建隔离。旧保存、自动恢复、保留和 v4 交接入口不能消费该事务。写后登记成功但清日志失败时，历史 A 原本没有页标记；显式恢复以固定记录和完整原字节证明授权续写，不将历史 A 错当作当前丢失契约的文件。PDF 保持租约并重新计算实际摘要；完成后重新打开当前文件，核对实际 B 后才返回有序页目录。

## 验证与边界

37 项定向测试全部通过（Editor 13、MapStore/消费者 8、旧 MapSession 7、选择器 2、页面启用 7）；全量 334 套 3640 项测试，0 失败、错误或跳过。Android 测试源码编译通过，未执行。定向日志 `tmp/stored-copy-page-activation-focused-green.log`、全量日志 `tmp/stored-copy-page-activation-full.log` 及计数 `tmp/stored-copy-page-activation-full-summary.json` 均在已忽略的 tmp/。独立复核了原生副本、界面回调、导图日志和页面启用权限。

行为红包括正常共享导出因 BundleHeader 实例相等判断而失败（92043 定向日志），已改为核对实际身份及标记字段；坏标记的 JsonPullException 现归入元数据契约错误，保留取消、PDF、IO 与权限异常语义。旧日志保护复核补上本次未同步 staging 的限定清理，并由部分写入后取消／重试用例验证。页面启用 API 红记录为 `tmp/page-activation-storage-api-red.log`。

新增用例覆盖实际存盘笔记／画布／导图复制、PDF 原件与 GC 租约、当前草稿及撤销保持、非空目标零写、取消、写后失败与固定候选恢复、URI 别名及 staging；页面启用覆盖 A/B、外部 C、权限错误、坏标记、越权候选、首发记录替换和旧入口拒绝。

Robolectric 的 resolver 会调用 DocumentsProvider 已停用的 pre-O query 重载，实际抛出 UnsupportedOperationException。测试适配层仅将该边界转交同一 provider 的 queryDocument/openDocument 与实际文件，不伪造保存结果；单独登记已启用页契约的降级反例明确设置 pageReferences=true。源码复核及主机结果不代表系统 DocumentsUI／SAF、Android 仪器或 MovinkPad 验收。

未运行系统选择器、真实 SAF 权限恢复、实际 PDFium、MovinkPad Pro 14／Android 15／Pro Pen 3、GPU、掌触与大文件性能。本片不修改笔迹渲染器或前缓冲。
