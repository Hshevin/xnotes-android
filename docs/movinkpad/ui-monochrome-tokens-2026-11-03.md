# 黑白层级与字号、间距规范（2026-11-03）

状态：已实现，单元测试与模拟器截图已检查；MovinkPad 真机视觉验收待执行。

## 约定变化

用户于 2026-11-03 放宽界面颜色约定：仍然只用黑白，但允许用中性灰阶（R = G = B）表现层级。彩色强调色、渐变和装饰阴影仍然禁止。笔迹颜色和 PDF 属于内容，不受界面主题限制。

## 调色板（`ui/theme/MonochromePalette.kt`）

纸面、工具栏面板和菜单保持纯白 `#FFFFFF`（夜间为纯黑 `#000000`），选中态仍用完整黑白反转。其余角色按前景色混入的比例取值：

| 角色 | 亮色 | 夜间 | 用途 |
| --- | --- | --- | --- |
| `bg` 页面四周背景 | 4% | 12% | 页面外的画布空隙、主页内容区 |
| `surface` 填充 | 6% | 18% | 未选中的标签、按钮底色 |
| `surfaceHi` 加深填充 | 10% | 26% | 悬停、按下等更强一级的填充 |
| `border` / `paperBorder` 分隔线 | 14% | 30% | 分隔线、页面边缘 |
| Material `outline` | 54% | 54% | 开关、输入框等需要 3:1 对比度的控件边框 |
| `textDim` 次要文字/图标 | 62% | 62% | 次要文字、未选中的工具图标 |

夜间四级灰阶已于同日加深（原为 6% / 10% / 15% / 20%）：纯黑纸面、工具栏和菜单旁原来几乎看不出层级。见 [AI 界面、夜间层级与双语](ai-ui-dark-i18n-2026-11-03.md)。下方夜间截图为调整前的样子。

`MonochromePaletteTest` 检查以下几点：所有角色都是不透明灰；亮色与夜间互为反色；次要文字对比度 ≥ 4.5:1，控件边框 ≥ 3:1；分隔线比文字弱但仍然可见；夜间纸面保持纯黑，让夜间笔迹显示逻辑继续生效。

## 字号与间距（`ui/theme/Tokens.kt`）

- `TextSize`：界面只能用以下字号 10 / 11 / 12 / 13 / 14 / 16 / 18 / 20 / 24 sp（`micro` 到 `display`）。原有的 15 种字号已统一映射：半档向上取整，15 → 16，22/28 → 24。纸面内容（文本笔记、模板、PDF）的字号不受此限制。
- `Space`：padding、`spacedBy` 和 Spacer 只能用 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 dp。原有数值的映射方式：小于 8 的奇数向下取，10 → 12，14 → 16，18 → 20，28 → 32。1 dp 只用于分隔线偏移；88、96、150 dp 这几个是结构性偏移，没有改动。控件本身的尺寸不算间距。
- `MinTouchTarget = 48.dp`：工具栏三档的按钮分别为 48 / 52 / 56 dp（原来是 36 / 42 / 50），紧凑档只缩小按钮里画出的图形。分屏标题栏上的文件夹和关闭按钮也改为 48 dp。

## 同时清理

- 删除"OLED"外观选项。旧设置里保存的 `oled` 读取时会转成 `dark`，有单元测试覆盖。
- 删除未被调用的 `CustomMaterialControls`，以及只被它使用的字符串资源。
- 去掉浮动工具栏、提示框、文件浏览器浮动控件和置顶栏、侧栏拖动卡片、新建笔记封面上的阴影，改为依靠边框或反色区分。取色器渐变和新建页滚动淡出属于功能性提示，保留。
- 分屏标题栏的整圈黑框改为浅分隔线；分隔条平时用分隔线颜色，拖动时才变为满色；窗格标题垂直居中；标题栏操作图标改为次要灰。
