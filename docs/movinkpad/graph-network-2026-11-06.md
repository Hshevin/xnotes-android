## 已核实的复用能力

- mindmap/MindMapDocument、MapHistory、MapCodec、MapStore、MapSession：不可变快照、节点 ID、独立文件、恢复日志和覆盖前摘要检查。
- MapPainter、MindMapView、InkPadView、MapNodeDialog：原生 Kotlin／Android Canvas，复用 StrokeEngine／AndroidRenderer；现状为事务式弹窗编辑，尚非需求规定的原位／占据窗格编辑。
- storage/NotebookStorage、DocumentRegistry、format/BundleIdentity、BundleMigration：持久文档 UUID、重复身份保护、SAF 迁移日志和字节保真发布。新引用不得以文件名作为身份。
- core/model/Page.uid：明确是未持久化的进程 ID；CanvasItem 没有持久对象 UUID。页面／对象跟随引用必须先增补持久身份和后继关系，不能直接引用 uid、页码或内存对象。
- Editor／MainActivity：保存后替换工作区、双窗格跳转和文档打开失败保护；PdfResources：不可变原件与租约。不得为预览复制整份 PDF 或清理受管原件。

## 落地规格与验收映射

1. 概念节点保留稳定 ID，正文类型与来源列表独立。来源有独立 ID、documentId、范围、备注、最后预览描述、版本及状态；主要预览按来源 ID 指定，删除或排序不改变正文。仅来源节点作为独立正文类型。不同位置不得因同一 documentId 合并。
2. 图内可有自动布局树与自由节点组成的森林。自由根必须显式标记，核心根仍保护；层级无环，普通线与父子关系独立。三种布局作用于自动分支，整理先预览，可取消，确认一步撤销。自由位置保存，不随正文编辑整理。
3. 普通线有独立 ID、端点、四类语义、方向和说明。无向关联 A—B 与 B—A 去重；有向线按有序端点区分。删除节点清除其普通线；删除线保留节点。连接创建和节点创建可用一次快照提交。
4. 编辑按用户需求第五星完整执行：落笔锁定归属、不裁掉原始轨迹、框稳定、节点工具作用域、共享内容历史、视口恢复、文本原位输入。当前框内夹紧坐标的旧行为必须替换并补事件回归，不能宣称已满足。
5. 来源范围为文件、稳定页、PDF 区域（原文／特定批注上下文）、对象 ID 集、固定区域。页身份和对象继承落地前不启用对应入口。来源创建须通过现有登记读取／校验；不能把用户输入路径当成可信身份。
6. 反向引用为可重建索引，权威记录始终在图中；导航定位 graphId/nodeId/sourceId。索引写失败不丢图，不把索引当备份。
7. 文件网络区分真实内容引用、显式用户关联、可选同图出现。多来源概念只产生“概念→来源”边，不推导文件彼此依赖。按文件身份聚合并保留解释路径。
8. 改名／移动跟随登记；外移／权限缺失保留最后预览并提示；重复身份拒绝任意选择；对象部分删除、全部删除、空区域、回收站、永久删除用独立状态。定位与替换来源分开。仅剩预览时只能保留图片。
9. `.xmap` 扩展使用 v2，读取 v1 不写原文件；新模型保存 v2，旧版明确拒绝 v2；已有笔迹采样值不改。预览不是备份，不隐含打包被引用文件。沿用既有恢复日志和限额，未知版本拒绝覆盖。

B1：原位笔输入、窗格放大编辑与文本输入。验收：越框轨迹不丢、掌触顺序、取消、工具锁定、共享历史、视口恢复。事件契约；目标硬件单列。
B2：页／对象身份及后继映射。先建立独立元数据与字节保真迁移，覆盖移动／跨页／碎片／撤销／复制不继承；失败保留原件。依赖 A1，不因急于引用而重编码旧笔迹。
C1：整文件／页／PDF 区域／对象／区域来源入口、图及节点选择、多来源列表排序／范围编辑／预览与刷新。依赖 B1/B2。恢复／重复身份拒绝和大 PDF 可取消预览。
C2：单窗格及双窗格来源往返、定位轮廓、侧栏反向引用和失效恢复。依赖 C1，覆盖保存失败不换文档、原 PDF 指纹保护。
D：当前文件局部网络、文件夹／类型／集合筛选、逐层探索、同图出现可选、加入手工关系画布；全库索引按需构建。依赖 C2。
