## 本阶段规格

- 来源列表逐条打开；引用节点仅有一个来源时双击走同一路径，多来源先选择具体条目。文本和手绘节点双击仍编辑主体。
- 首先支持分页笔记／批注 PDF 包装的整文件、永久页面与已有页面区域提示。画布与导图文件来源先明确提示尚不支持打开，引用及最后预览保留；其余原需求继续实施。
- 当前导图是主窗口中的单文档。跳转来源不恢复停放的旧分屏；已打开来源保留实际拥有者、原物理槽、模型、修改和历史，其余文档经过原保存／放弃／取消保护后收起。
- 来源按文档 UUID 与永久页 ID 核验。已打开模型中的已删页面不从磁盘旧页复活，不用页码改指；登记的身份重复、不可访问、缺身份或坏页面目录都拒绝自动选择。打开不补身份或迁移来源。
- 来源票沿现有会话代次与成员寿命，备注、排序和预览更新不废票；范围更换、删除后撤销、重载及旧宿主回调不能采用新成员。保存已接受版本的证明与预览摘要分开，保留已写版本的原有规则继续有效。
- 最后纯核验包含图当前无未确认编辑事务；核验、原生采用和图隐藏同在 Main 上完成，中间不挂起。之后资源清理的迟到结果不能回滚已成功切换。
- 定位轮廓是临时阅读标记，按实际页对象、纸面范围与视图变换绘制，不改选区、内容、脏状态或撤销；需等待真实重挂与布局，不能以旧隐藏视图的尺寸提前完成。
- 返回先等待原生笔与保存事务稳定，实际展示原图后恢复选择和具体来源条目。普通「查看导图」不消费旧返回选择；图世代变化拒绝旧返回，来源成员失效仍可回同一世代图但不误聚焦其它条目。
- 来源备注 IME 缩屏前保留普通相机；隐藏、取消、失败与返回的过渡尺寸不能覆盖它。失效来源的收尾须解除相机保护，使之后的平移缩放仍可保存。
- 返回点只含图会话数据，不在保留的工作区中持有旧 Activity、原生 Editor、View 或预览位图。
