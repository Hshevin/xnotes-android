## 顺序调整的依据

页面来源不必等待整个NativeWorkingSession生产迁移。现有固定快照已经在拥有者准备新增页面身份，NativeSaveContract拒绝原件与候选的页面标记模式不一致，登记契约按文档身份单调保留。NativeStorageSaveTest的实际anchored保存用例也证明普通发布能保留和登记页合同。

这项保护只覆盖经过NotebookStorage的发布。Editor.save(output)与主界面CreateDocument仍会直接打开输出流，不能用上述契约为其背书；主界面的另存副本也在调用copyFileTo之前打开输出流，createNoteFile会直接写入并在失败后删除目标，旧另存和冲突分叉还仅换文档身份、沿用页身份；这些出口也必须修复。它们是接通页面引用时需要一起修的小范围出口，不能留下覆盖已启用文件或重复页面身份的路径。

完整native4／同head改造仍是保存恢复的独立方案；是否采用它应由实际失败行为决定，不把已有但未使用的接口自动提升为页面功能的前置要求。原产品的保存失败保护、异常退出恢复、源文件变化与恢复要求均继续保留。

## 下一条可验收路径

1. 为实际已保存的分页笔记／PDF包装文件显式启用永久页身份，使用BundleAnchors原字节候选。复用现有发布日志、原件保护与校验，不重编码笔迹或PDF。启用必须绑定实际UUID、来源摘要、位置及同一候选；写后失败保留候选以供明确继续，不重新分配页面编号。
2. 成功后重新读取实际文件的有序页目录，按真实页面编号创建PAGE来源，并加入已有节点或新引用节点。保存重开`.xmap`后保持编号；画布继续按文档UUID引用。
3. 当前编辑器的“引用此页”先等待稳定保存，再读取fresh catalog核实际模型UUID、当前页永久编号与磁盘目录；旧native3保存后的lastReadSourceVersion不冒充最新保存回执，也不另造模型→EditSource授权工厂。不能把目录中的第N个编号贴给旧模型的第N页。模型与来源不一致时提供重开／恢复，不猜测。
4. 直接新建输出、另存副本和createNoteFile（包含分叉／导入／空白新建共用入口）接现有NativeCreation空目标发布与PageReferenceCopy投影／采用。必须在外层打开输出流之前核对目标；不能仅在save(output)内部检查已经被截断的文件，也不能在失败时删除provider返回的未知或非空目标。同目标使用受校验的普通保存；新副本的文档和页面身份必须与原件独立。不中途删减已有另存功能。

启用的重启续写须重新证明保留的A→B只改变页ID literal与marker：核对非manifest原始负载及manifest其余片段，不能仅凭格式／UUID／marker／候选摘要签发这种狭窄修改权限。验证使用原字节扫描，不通过模型重编码；新purpose由旧ensure／save／keep／restore明确拒绝自动消费，不能落入canvas兜底。

另存／分叉的最小屏障沿用已有保存机制：等待旧native任务与已接受的legacy前缀，稳定捕获固定正文；用现有saving modal冻结本次编辑，避免再引入并发C1交接。Main采用前核实际owner／模型／身份／revision／请求票，成功后退役旧来源context，按原owner采用PageReferenceCopy，再固定保存工作资料。失败保持原scope／path／dirty；若后续允许IO中编辑，则新增内容仍须保持dirty，不能用旧快照的成功回执清零新修改。

MindMapActivity本身没有打开源文件，不证明整个进程没有活编辑器。不得用不可靠的“文件已关闭”判断授予覆盖权限；实际源版本、发布锁、摘要复核、单调登记以及全部写出口的校验共同保护原件。

## 验证要求

- 真正执行启用、读取目录、选择第2页、加到节点、保存重开；核PDF与非manifest条目原始字节不变。
- 激活后让仍未带页编号的旧模型通过实际保存入口尝试写回，拒绝覆盖；直接输出出口也必须拒绝非空目标或走受校验保存。
- 系统选择器或provider把非空原文件作为目标返回时，各创建／副本／新建入口均在写流打开前拒绝，写入和删除次数为0；发布失败保留原件与恢复资料。
- 写后登记失败使用同一候选继续；取消、权限丢失、外部同UUID内容变化、坏标记与重复／缺失编号均不提交虚假PAGE来源。
- 以generic stage伪造同UUID、合法marker但改笔迹／原PDF／未知字段的启用候选，首发及重启续写均拒绝，保持原件及日志；不能只测私有正常候选。
- 已启用文件的新页、复制页、重排、删除及撤销重做保持正确身份；另存和分叉新页编号与原件不相交。
- 来源选择器的迟到结果绑定原图／节点草稿，不覆盖新正文或来源列表。Android平台行为及MovinkPad另列实测，不能以主机结果替代。
