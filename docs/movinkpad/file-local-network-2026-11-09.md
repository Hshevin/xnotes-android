## 规格与分工

- 初始从笔记／批注 PDF 的「引用与关联」进入。使用实际文档 UUID 捕获中心文件，先等待原生两个窗格的输入稳定再展示。网络查询随后由自己的生命周期管理，保留纯中心身份、授权根、轻量关系证据及视口，不持有旧 Editor／Activity／View。
- 同一次图读取中寻找引用中心文件的概念，再投影这个概念的全部来源。文件按文档 UUID 去重，概念按规范图位置＋图 UUID＋节点 ID 区分。概念引用来源文件、概念属于图是两类真实证据；同一概念的多个文件之间不自动产生引用或依赖，不从普通概念关系或同图出现推导手工文件关联。
- 同概念指向同文件的多个页面／区域可聚合显示数量，但每个来源成员、永久页 ID、范围提示、备注及最后状态都保留，供逐条选择。旧状态只表示图中最后记录，本次不重新读取笔记或 PDF 正文。
- 复用现有实际资料发现、规范 URI 锁、只读恢复赢家和活会话覆盖。加载中的活图不回退磁盘旧图；普通 C1 只重新投影，不重新遍历全库；目录、权限、身份、恢复或大小失败明确显示不完整。
- 全局读取预算沿既有 4096 个目录／图、256 MiB、5000 个轻量成员及 128 个具体问题。场景独立限制 250 节点、750 条实际边，必须把概念所属图的边一起计算。按完整概念原子接收，不能截成丢失中心来源的半组或产生悬空连线。
- 使用现有 MindMapView／MapPainter 的派生只读场景，不进入 MapSession，不保存成图文档，不改原笔迹、布局、折叠或撤销。点击选择与查看解释；拖动只平移视图，双指缩放，笔和掌触按真实输入归属隔离。取消、重挂及模式变更须排空旧事件流，直到新的 DOWN 才重新接收。
- 从网络打开图时同时核实「概念仍引用中心 S」与「用户选择的具体来源 T」两个原成员能力。T 可与 S 不同，不伪造原生文档上下文，不放宽旧反向引用单成员入口。存盘记录只能由本次操作自己创建的新 actor 首次取得双证明；旧行不能转绑到后来出现的活会话。
- 最后展示须重新核网络当前 View 代次、单调输入票、无活动手势、双成员、原生停车及目标图编辑就绪；异步检查期间新落笔会永久退休这次跳转。成功前保持网络，成功后可回同一网络视口和选择，不丢未确认图编辑。
- 网络发起的图展示使用显式纯停车标记，避免现 Main 展示图时的 persist 副作用强制保存原笔记；普通打开图的原有行为保留。应用真正进入后台仍按原持久化规则处理，不取消已接受写入。

Root 负责纯模型／完整概念预算／场景、双成员访问和导航、工作区／主界面／字符串与文档；source_loop_audit 负责共享读取投影、Controller 和真实 provider 测试；cancel_event_tests 负责只读原生事件与共享主机／Android 测试。review_network_plan 独立只读复核，不运行构建或派生代理。所有 Gradle 和本地提交由 Root 统一，生产与测试冻结后才运行。

## 产品入口与返回

笔记／批注 PDF 的「引用与关联」现可打开「局部关系网络」。中心 S 在首次入场后属于纯查询，不跟随后来阅读的 T 改变。只读图展示文件、概念、真实引用和所属关系；解释栏列出具体来源及最后记录的状态，选择一条可打开同一编辑 actor 的具体节点／来源。此时仍同时核实原概念引用 S 及所选 T 的原成员寿命。

从该图打开来源 T、返回图、返回网络均保留原中心、相机和有效选择。普通返回可停放脏图；未确认文本事务先阻止切换。关闭／替换／销毁图清旧停车闭包，普通 backlink 替换也退休旧网络返回链，避免配置重建后持有旧 Editor。网络查询及相机由实际 ViewModel 保留，新宿主必须重新取得原生停车证明；旧输入票、旧宿主或新 DOWN 不能续用旧请求。

打开存盘图会先创建 LOADING actor。此期间只冻结已呈现的视觉报告与场景，状态提示使用叠层，不调整 Canvas 尺寸；真实 Controller 继续报告当前 LOADING，不回读旧磁盘、不能发起第二次打开。冻结期间连未展示报告的 builder 都不调用，防稳定位置缓存被清空。取消／失败后立即采用当前报告，消失选择保持为空，不擅自改选中心。
