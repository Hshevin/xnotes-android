# 画布内思维导图 v2 文件格式（2026-11-21）

用户要求：完成阶段二，将阶段一的导图模型写入画布包，覆盖打开、保存、复制、迁移和恢复路径，验证普通画布兼容性。
状态：已验证（JDK 21，完整 JVM 单元测试 5,119 项通过，零失败、零跳过；仪器测试源码编译通过）。
本轮边界：本地源码、测试与提交。未打包、安装、推送或发布。

含导图的画布在身份条目后、清单前写入压缩的 `map.json`，清单标记为 `xcanvas-map`。创建第一棵树和删除最后一棵树均可原位保存，文档 UUID、文件扩展名及登记类型保持为原画布的值。旧版读者依据清单标记拒绝打开含导图的画布。

读取时先核对标记与条目是否配对，再把通过结构、版本和根图层检查的模型交给编辑器。实际解码失败会清理本次提取的资产。原字节迁移在生成身份候选前检查导图，复制使用原条目流及摘要。节点笔迹使用画布既有的采样精度和速度笔通道。旧收尖笔缺少尖端系数时沿用历史值，未启用收尖时使用普通笔的默认值。

| 流程 | 新增回归覆盖 |
| --- | --- |
| 编解码、参考信息、原包复制与导出 | `MapBundleStorageTest` 核对节点与画布速度笔的序列化字节、失败清理、无身份包迁移、独立副本与便携导出的条目字节，以及损坏或未来版本的迁移拒绝。 |
| 原件识别与保存 | `NativeEditSourceTest` 核对首次加入及最后删除导图后的识别、发布、登记和原 UUID。 |
| 工作会话与交接 | `NativeWorkingRecoveryTest` 核对带导图正文的保存交接、仅视图更新复用正文、从工作会话恢复并写回原件。 |
| 写入中断恢复 | `NativeStorageSaveTest` 核对实际目标已写成普通画布时，显式恢复仍能找回带导图原包的完整字节。 |
| 受保护的画布与恢复副本 | `PreparedProtectedCanvasTest` 核对解码和采用的导图。`RecoveryCopyTest` 核对预览模型、新身份及原始条目字节。 |
| 编辑器入口 | `EditorWorkingCheckpointHostTest`、`EditorPageCopyHostTest` 分别核对呈现检查点正文及文件浏览器复制结果。 |
| 录音恢复凭据 | `RecordingRecoveryStoreTest` 从同一画布核对文档类型、整包摘要、录音编号与音频摘要。 |

写入规则和版本 1 模式见 `MapJson.kt`。缺省根图层为 `default`，存在的样式对象需提供完整字段。原字节复制保留额外字段、空白和数字拼写。树节点标题、来源和关系等可编辑字段按[阶段设计](mind-map-v2-design-2026-11-21.md)保存。

验证使用 Gradle Wrapper 8.13，运行 `:app:testDebugUnitTest` 与 `:app:compileDebugAndroidTestKotlin`。完整套件包含原有的 `CanvasMapCodecTest` 22 项、`CanvasCodecTest` 71 项。本阶段新增 13 项回归测试。未连接设备，未执行仪器测试或真机文件系统验收。
