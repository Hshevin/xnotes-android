## 框架

新包 `com.xnotes.map`，与旧 `com.xnotes.mindmap` 完全独立，旧包在新导图可用后整体删除。

```
MapState      不可变数据：节点、父子与顺序、树根位置、每棵树的布局方向、偏移、关系线（全部进入内容撤销）
MapModel      持有当前 MapState 与折叠集合（折叠不进撤销）；变更通知投影层
MapEditor     全部编辑操作；每个操作 = 一个 core.history.Command，保存前后两个 MapState
MapLayout     纯函数：MapState + 折叠 + 节点尺寸 → 每个可见节点的矩形、树线锚点、隐藏集合
NodeMetrics   节点尺寸：标题测量（TextMeasurer）+ 手写区 + 来源标签行 + 内边距
MapHit        命中与拖放判定：点中哪个节点、拖到哪里算换父／插为同级／微调／非法
MapClipboard  子树复制与粘贴（新身份）
—— 阶段二 ——
MapCodec      写入画布 ZIP 包（独立条目 + 版本）；含导图的画布提高格式版本
—— 阶段三 ——
SourceRef 解析  文档 UUID／永久页编号 → 可跳转目标、已删除、缺失
—— UI（我）——
MapProjection 把可见节点、树线、关系线投影成画布对象（节点对象实例按 id 稳定，关系线粘接不断）
画布集成       导图工具、手指／笔分派、＋柄、浮动菜单、样式面板、来源选择器、返回导图
```

原则：

- **位置只有两种是权威的**：树根的左上角和子节点的偏移量。其他所有坐标都由布局派生，所以撤销只需恢复 `MapState`，再重新布局。
- **撤销用整份状态快照**：命令保存操作前后的 `MapState`（不可变，结构共享），撤销／重做直接替换，不会出现局部回滚不一致。与画布共用同一条 `History`。
- **折叠不进撤销**，单独保存在 `MapModel`。撤销恢复的旧状态里如果出现折叠集合中已不存在的节点，就忽略它，保存时再清理。
- **节点手写存为节点局部坐标**，移动节点和重新布局不改写笔迹；只有写入时把世界坐标平移一次，压力、时间等原始采样保持不变。
- **新建节点是草稿**：先不进历史，确认文字后创建与文字合成一步撤销；取消则不留任何痕迹。

## 手动调整节点大小（2026-11-26）

用户要求：节点大小改成手动调整，在节点里画画时笔迹不能超出边界。用户选定：超出部分直接裁掉；没有手写区时第一笔决定大小；选中后拖右下角调整。

- 数据：`MapNode.width` 记手动宽度（为空则按内容定宽），高度由手写区高度承担；存档写可选字段 `width`，不提高格式版本，旧版应用忽略该字段按内容定宽。
- 尺寸：`NodeMetrics.resized` 按目标尺寸算出宽度与手写区高度；不能小于已写笔迹，标题按新宽度换行，没有笔迹且手写区不足 `RESIZE_MIN_INK_H` 时不留手写区。手写区始终占满节点内宽。
- 裁切：`MapEditor.addInk` 给存入的笔迹加上手写区四条裁切边（`Stroke.cuts`），原采样全部保留；已有手写区时不平移、不扩大，裁完看不到的笔迹不写入、不进撤销。书写中由 `MapController.inkCuts` 给实时笔迹加同样的裁切边，前缓冲与画布同样只显示框内部分。
- 界面：选中节点右下角出现方形手柄，拖动时实时预览、松手合为一步撤销；调整中隐藏「＋」柄。

## 新笔迹压在节点上方（2026-11-27）

用户反馈：当前图层的笔迹与节点相交时，要再写一笔，节点才盖到它上面。

- 原因：用前缓冲书写时，抬笔后笔迹先留在前缓冲上，等交接完成才进入画布场景，这时排定叠放顺序的消息已经先到，场景找不到这笔就跳过了，笔迹落到最上层；下一笔再排一次序才归位。
- 处理：`CanvasScene` 记下排序时还没到的条目的位置，条目到达时直接放进去，由 `CanvasSceneHiddenLayersTest.anItemThatArrivesAfterItsOrderTakesItsOrderedPlace` 检查。普通对象之间的叠放也同样受益。
- 验证：JVM 单元测试 4,030 项全部通过，仪器测试源码编译通过；前缓冲交接的实际效果待真机确认。
