# 原生思维导图第一版（2026-11-06）

用户要求：新建工作树，用原生 Kotlin 实现文本框／手绘框节点的思维导图，功能参考 XMind，使用独立文件格式，不要求 XMind 格式兼容。
状态：已实现；2734 项 JVM 测试通过，Android 仪器测试源码编译通过；目标设备验收待执行。
本轮边界：独立工作树及本地提交；不打包 APK、不安装、不推送、不合并、不发布。

## 规格与验收

- 首页文件浏览器可创建、打开 `.xmap`，文本与手绘节点混排；手绘保留压力、时间及可编辑笔迹。
- 节点增删、同级／子级、文字编辑、手绘编辑（笔、整笔橡皮、套索移动）、折叠展开、子树拖动、拖至另一节点更换父级、自动左右布局、缩放平移和适合窗口。
- 撤销重做以完整操作为单位；取消手势不改模型，删除子树可完整恢复。根节点不可删除／换父级，禁止循环。
- 独立 JSON 容器：`format=xnotes-mind-map`、`version=1`、文档 UUID、节点 UUID、父子顺序、布局、文本、节点局部坐标的矢量笔迹。未知版本、坏树、重复 ID、非有限坐标及超限内容拒绝读取，不覆盖原文件。
- 本地恢复日志先原子提交，再尝试写 SAF 目标；失败保留恢复副本。重开有恢复内容时明确提示；目标遭外部修改时拒绝覆盖，提供另存副本。保存与读取在 IO 线程串行执行。
- 第一版独立编辑页，不加入笔记／PDF 双窗格；复用现有笔迹几何和 Android 渲染，不复用分页湿墨 View。黑白主题与三套中英字符串资源；触控区和界面排版使用 Tokens。
- 首版不包含：XMind 文件兼容、图片附件、云端同步、关联线／概要／外框、鱼骨／时间轴、完整快捷键映射、GPU 前缓冲。

## 实现顺序

1. 纯 Kotlin 模型、树操作、历史、布局及失败用例。
2. 严格格式读写和可恢复存储，往返／坏文件／失败恢复测试。
3. 原生导图视图和节点编辑，Android 事件测试。
4. 文件浏览器入口、文档识别、分享／复制与预览隔离；回归测试和文档。

## 结构与代码约定

源码集中在 `app/src/main/java/com/xnotes/mindmap/`，JVM 测试在 `app/src/test/java/com/xnotes/mindmap/`，事件测试在 `app/src/androidTest/java/com/xnotes/mindmap/`。无新增依赖。采用不可变数据及显式变更，例如 `node.copy(collapsed = !node.collapsed)`，历史不持有可变 Stroke 实例。显示文字使用资源；持久化字段稳定使用英文。

## 实现与验收结果

工作树：`<工作树 mind-map>/xnotes`，分支 `codex/mind-map`，基于 `47256b5a`。原工作树保持干净，未合并任何其他分支。

- 主界面使用原生 Compose；导图和手绘区域使用单个 Android View／Canvas，复用既有 StrokeEngine 与 AndroidRenderer 的矢量笔迹。编辑页独立于分页／无限画布共享工具栏，不添加共享工具类型，不改现有笔按键状态机。
- 首页新建入口创建 `.xmap`，节点框可切换文本／手绘（有笔迹时须先清空才能切回文本，清空可撤销）。支持节点列表选择、更换父节点及键盘上下选择／回车编辑。
- 文件复制产生新的文档 UUID，保留节点及笔迹；分享保留文件身份。文件类型、预览、复制、导出均单独分派，不送入笔记 ZIP 编解码；不允许作为分屏配对。
- 撤销历史最多 80 步。格式限制为 1000 个节点、128 层、25 万个笔迹采样点、节点边长 48–4096、每节点 2 万字符；文件读取上限 32 MiB，编码时预留 4 KiB 恢复日志封装空间。超限拒绝，不静默截断内容。
- 保存先 fsync 本机暂存，再以原子移动提交日志，随后核对目标摘要、写入并回读校验。最新编辑版本才可显示「保留本地恢复副本并关闭」。同一 URI 的读取与写入共享进程级互斥锁；目标被外部改动或写坏时保留恢复资料，转为另存副本。
- 编辑防抖保存间隔 350 ms，退后台主动提交；已开始的写入不随 Activity 销毁取消。尚未点击「完成」的节点编辑是临时草稿，取消或进程终止不提交这部分草稿。
- PDF 复用项目已有 PDFBox，导出为一张 2382×1684 的白底阅读快照（单页 PDF），不包含可编辑节点或可选择文字。完整备份使用 `.xmap`，大图 PDF 清晰度与分页导出属于后续改进。
