# 顶部 AI 入口、统一截图交互与思考强度兼容（2026-11-22）

用户要求：在顶部工具栏新增「AI」按钮直接呼出 AI 悬浮窗；统一 AI 悬浮窗内「再截屏」与顶部工具栏截图表现（截完自动展开浮窗并切回原工具），并让无限画布截图对齐分页笔记（8 手柄缩放、内部拖动与自动切回）；解决 gpt-6.2 系列模型思考强度不支持的报错并扩展 `minimal` / `xhigh` 档位。分工：主代理负责前端与全部测试用例，`gpt-6.2-astra` 负责后端实现与测试复核。
状态：已实现；JVM 单元测试与 Android 仪器测试源码编译通过（本机 JDK 21）；真机手势手感、真实供应商响应待验证。
本轮边界：源码、测试与文档本地提交；不打包 APK、不安装设备、不推送或发布 Release。

## 改动摘要

1. **顶部工具栏 AI 按钮（`ToolbarItem.AI`）**
   - 纳入 `ToolbarLayout` 穷尽分类（`ToolbarScope.COMMON`，支持笔记、PDF、无限画布，分屏进入顶部共用栏且不重复显示）；老布局升级自动插在「截图」按钮之后；修复 `workspaceToolbarLayout` 去重逻辑，尊重分页布局中对项的隐藏配置。
   - 点击未打开的悬浮窗时为当前文档新建会话并展开（PDF 笔记同步提供当前 PDF）；悬浮窗已打开时在折叠与展开间切换，折叠保留未发送草稿与空会话，展开结束捕获模式。
2. **统一截图功能与无限画布对齐**
   - 分页与无限画布截图菜单统一采用「导出 PNG → 目标接受成功后再清框并切回原工具」：AI 接收后自动展开悬浮窗、结束捕获模式并恢复各窗格截图前的工具（不限于笔类工具）；达到附件上限或导出／复制失败时保留原选框、截图工具与捕获态。
   - 无限画布冻结截图框新增 8 个调整手柄（带反色描边，黑白纸面与图片均清晰可读），支持笔与手指（即使关闭手指绘画）拖动缩放、拖内部移动、取消或双指打断恢复原选框、笔调整中忽略手掌第二指，以及完成后自动切回原工具；调整手柄命中优先于下方导图节点。
3. **思考强度扩展与 gpt-6.2 拒参自动降级**
   - 新增 `minimal`（极低）与 `xhigh`（超高）两档思考强度，AI 界面多于 5 档时自动折行药丸选择并保持 48 dp 触控区；同步中英文字符串资源。
   - `AiConnection` 保留原始错误响应体传给 `AiThinking.refused`，识别 JSON `error.param`（如 `reasoning_effort`）及无 `error.param` 时的等价字段名（`reasoning.effort` / `reasoning effort`）与对应发送值拒参文案（如关闭发送 `none` 或 `minimal`/`xhigh` 被拒），并确保先于 `AiToolsUnsupported` 判定以保留联网／PDF 工具；无关参数（`image_detail`、`temperature`、`max_tokens` 等）不误触发降级。
