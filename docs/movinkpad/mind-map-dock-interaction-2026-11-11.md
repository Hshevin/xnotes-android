# 思维导图停靠面板与交互改进（2026-11-11）

用户要求：改善手绘工具不足、节点难拖动及返回集中左上角的问题；新建节点时点击侧栏外收起并自动取消新建；侧栏改为可拖动到左右吸附的 dock。子代理默认使用 Astra，主代理负责规划、测试和验收。
状态：已实现并通过定向 JVM／Robolectric 回归和 Android 测试源码编译；Android 实际运行及 MovinkPad 真机待验。
本轮边界：源码修改、测试与自动本地提交；不打包、安装、推送或发布。

## 操作变化

- 菜单保持满高覆盖面板，拖动标题水平跟手，松手吸附最近的左侧或右侧；普通收起再打开保持停靠侧。面板不改变原生画布尺寸和视口，拖动取消或第二指介入恢复原侧。
- 在菜单外完整轻点，收起菜单；新建子节点、同级、自由节点或连线新节点的未提交草稿随之取消，不创建节点或历史。外部拖动和多指不触发取消；用于收起的完整手势不穿透到画布。已有节点不因收起而删除。
- 手绘节点正文可用手指直接拖动，笔仍在正文书写。停顿长按不再取消节点拖动，双击编辑保留。来源条在轻点抬起后打开，从来源条拖动不会打开来源面板。拖动以最终抬起坐标提交，取消与越界不提交。
- 原位与放大手绘共用新增直线、矩形框选和显式粗细入口；保留画笔、整笔橡皮、套索、适应内容、撤销与重做。直线只保存实际首尾样本，框选后拖动仅移动选中笔迹，取消不写内容。
- 文字编辑的完成和取消返回放在节点附近并限制在窗格范围内；放大手绘的返回固定在工具栏右端；菜单标题旁提供返回导图。

## 验证记录

主代理在共享 Android/JVM 事件契约中补充手指拖动正文、最终抬起坐标、取消、来源条拖动、直线首尾与冻结笔宽、框选移动与取消、稀疏线段中部命中及容量边界。已有多选手势回归继续运行。

独立源码复核发现直线中段选不中及最后两个采样额度误拒绝，新增用例在修正前分别以坐标不变、容量提示被触发失败；修正后按最终样本数量核额度，选区同时检查线段相交。复核同时将面板外任意手势关闭收紧为单指轻点。

真实 Compose 宿主测试覆盖外点取消创建与历史不变、就近取消文字、左右停靠与视口稳定、重新打开保留侧别。测试宿主补齐实际 View 绘制及可见边界检查，停靠测试明确使用 1800 × 1400 dp / mdpi 的平板窗口，避免只更新语义树、未放置布局的主机测试假象。Android 既有可见编辑用例同步新返回按钮名称；共享事件契约亦进入 Android 测试源码。

最终使用 JDK 21、Gradle Wrapper 8.13、Robolectric SDK 35，分批通过 `MapInputHostTest`、`MapNodeSelectionHostTest`、`MapGestureLayoutReviewTest`、`MapTextTransactionTest`、`InkPadDrawingRegressionTest` 和 `MapInteractionUsabilityTest`。最后一批 Compose 回归 10 项通过，无失败、错误或跳过；主程序及 `compileDebugAndroidTestKotlin` 通过。构建输出复用同步目录之外的测试目录，关闭 Kotlin 增量编译以避开本机增量元数据解析失败。没有新 APK，不能把主机测试或 Android 测试编译当成设备验证。待包含本次改动的测试包确认日夜间、分屏窄窗、软键盘下操作条可达性、笔掌并用与 MovinkPad 实际拖动手感。
