## 本阶段用户流程

在导图节点「来源」中选择文件后，可添加整文件，或从实际页目录选择页面。分页笔记及 PDF 批注笔记使用永久页编号；画布和导图只提供整文件。目录的「第 N 页」仅用于当次显示，保存的是页编号，来源列表显示「上次核对：第 N 页」，旧引用尚无位置提示时显示「位置待刷新」。页码只是显示提示，不作为定位或身份依据。当前使用文字目录，不生成缩略图。

旧笔记尚无永久页编号时，需要点击「启用页面引用」并单独确认。它只沿上一阶段的原字节启用事务写入页编号，保留笔迹、PDF 和其它负载。确认中说明已打开的旧编辑器可能需要重新打开；本片不按目录序号给旧活模型补编号。读取和选择保持只读权限，只有明确启用或继续启用时才尝试保留写权限。

选择页面后，可附加到已有文本／手绘／引用节点，也可加入从连线空白处创建的新引用节点草稿。已有正文与后续修改保持；新节点和线仍需原草稿确认才一起提交。一次来源追加可撤销／重做，`.xmap` 保存重开保持相同页编号。来源状态使用「未核实」，不冒称预览持续最新。

启用写后失败时，不先添加 PAGE 来源；界面保留原请求，允许用户明确继续同一候选，成功取得实际页目录后再选择。普通保存／新建的其它 pending 不会被误当作页启用消费。

## 请求、身份和取消

来源选择器属于原图／原节点或连接草稿的请求，直到最终选择才消费。先等待笔离开，再读实际来源核对 UUID、位置、摘要与页成员；读取期间又有笔接触则重新等待和验证。选择期间正文、笔迹和其它来源可继续修改，追加仅合并最新来源字段。

关闭来源面板、删除目标节点、改变连接草稿类型或替换图都会退休相应请求并取消所属任务。已在来源上完成的启用不会回滚；迟到结果不会写入新图或新草稿。系统文件选择器的旧请求占位保留到它自己的结果返回，避免关闭面板后把 A 的结果错交给 B；重建界面保留该占位。

原生来源沿实际文件头登记类型与单调页契约；JSON 导图使用单独的事务登记，不伪造原生文件头。同位置、同 UUID 的跨类型替换或已知页契约冲突都拒绝且保持原登记。重复可用位置需要明确恢复，不能按名称猜测。连接草稿在追加前核对完整限制，超出 128 个来源拒绝本次追加并保留原草稿，不静默截断。

## 原生文件创建与复制出口

原有创建 helper 已移除「先打开 SAF 输出流、失败删除返回 URI」的路径。笔记、画布、导图和 Markdown 各自使用正确格式的空目标发布；provider 返回非空文件、原文件或不可读取目标时，写流和删除次数为零。原生笔记复用受租约保护的 PDF 准备，不提前为尚未发布的临时文档身份永久 pin 原件；导图仍使用独立 JSON 和 MapStore。

自动分叉在 Main 稳定捕获前准备复制 scope／intent，IO 只投影固定正文；发布成功后再核拥有者、身份、路径、scope、来源 epoch 与 PDF 指针，采用实际身份／PDF。晚到内容保留为未保存修改，撤销恢复的旧页按副本 scope 取得新编号。只有采用成功后才登记后续保存路由；B 已写但采用失败不会把仍属于 A 的后续保存误送到 B。达到既定复制 lineage 上限仅拒绝新分叉，不阻断普通保存。

提取先等稳定输入，再固定正文、元数据和原 Page 对象；移动在返回后再次等待输入稳定，并核捕获版本。来源期间有修改时保留复制结果及原页面，不删除后来的内容。合并持各原 PDF 的租约直到合成和发布结束，为新 PDF 重建元数据；输入文件不变。PDF 导入关闭使用 finally。提取／合并写后取消保留候选和输入，不删除已发布版本；仍可明确完成同一候选。
